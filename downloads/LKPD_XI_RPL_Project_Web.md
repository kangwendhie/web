# LKPD XI RPL: Proyek Website Wisata Lokal

## Tujuan
Peserta didik mampu membuat website informasi wisata sederhana dengan struktur HTML yang benar, konten relevan, dan komponen halaman yang tersusun sistematis.

## Aktivitas
1. Pilih satu objek wisata lokal.
2. Susun struktur informasi: judul, deskripsi, galeri, lokasi, fasilitas, dan kontak.
3. Terapkan semantic HTML.
4. Tambahkan navigasi antarbagiannya.
5. Lakukan pengujian tampilan.
6. Publikasikan proyek melalui GitHub Pages.

## Produk
Satu website statis yang dapat diakses melalui URL GitHub Pages.
