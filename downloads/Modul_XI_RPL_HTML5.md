# Modul XI RPL: Struktur Dokumen HTML5

## Tujuan Pembelajaran
Peserta didik mampu membuat struktur halaman HTML5 yang benar, menggunakan elemen semantik, dan mengorganisasi konten secara sistematis.

## Pokok Materi
1. Struktur dasar dokumen HTML5.
2. Elemen `head` dan `body`.
3. Heading, paragraf, daftar, tautan, dan gambar.
4. Elemen semantik: `header`, `nav`, `main`, `section`, `article`, `aside`, dan `footer`.
5. Validasi struktur halaman.

## Tugas
Buat satu halaman profil sekolah dengan struktur HTML5 semantik. Publikasikan hasilnya melalui GitHub Pages.
